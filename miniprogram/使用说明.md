# 六爻 pro · 项目文件说明

## 你手上这个包是什么

`liuyao-coin-小程序.zip` —— 微信小程序完整工程，解压后可直接用微信开发者工具导入。

## 导入步骤（Windows / Mac 都一样）

### 第 1 步：解压
把 zip 解压到一个**固定位置**，比如 `D:\六爻pro\` 或 `~/liuyao-pro/`。

> ⚠️ 建议不要放在中文路径或带空格的路径下，部分工具会有兼容问题。
> 解压后应该有这样一层：`miniprogram/`，里面是 `app.js`、`pages/`、`utils/` 等。

### 第 2 步：装微信开发者工具
下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

Windows 装完是桌面上的「微信开发者工具」图标。

### 第 3 步：导入项目
1. 打开微信开发者工具 → 欢迎页点 **「导入项目」**
2. **目录**：选到解压出来的 `miniprogram` 这一层
   - 也就是要能看到 `app.json`、`pages`、`utils` 这些东西
   - **不要**选到上一层（选错了会提示找不到 app.json）
3. **AppID**：已经填好了 `wx828f1844efa44608`，不用改
4. **后端服务**：**不勾选**（本项目没有网络请求）
5. 点「导入」

### 第 4 步：编译 & 预览
- 等它自动编译完，左侧模拟器会显示出起卦页
- 点右上角 **「预览」**，手机微信扫码就能真机试玩

## 常见问题

| 现象 | 原因与解法 |
|------|-----------|
| 提示「未找到 app.json」 | 导入目录选错了一层，应选 `miniprogram` 而非它的父目录 |
| 提示 AppID 无效 | 确认导入的是解压后的新包；或检查 `project.config.json` 里 appid 是否被改动 |
| 真机预览打不开 | 检查电脑防火墙是否拦了开发者工具的端口；或手机与电脑是否同一 WiFi |
| 界面显示「装卦失败」 | 大概率是文件没解压全，确认 `utils/lunar.js`（426KB）存在 |
| 改了代码没生效 | DevTools 里点「编译」或 Ctrl/Cmd + B 重新编译 |

## 下一步：提交审核

⚠️ 微信对**算命 / 占卜**类内容审核严格，目前没有标准开放类目，个人主体大概率被驳回。

如果只是想自己用，其实**不需要审核**——微信开发者工具里点「预览」扫码即可，本地就能玩。

若要上架，建议：
- 类目选 `文娱 → 资讯` 或 `工具 → 其他工具`，避开占卜/命理/宗教字样
- 简介写「铜钱起卦传统文化演示」，文案避免「算命/预测命运/灵验/转运」等词
- 不接入支付、不引导加微信或跳外部链接

审核不通过也别担心，还有 Web 版单文件方案：解压完整项目包里的 `index.html`，双击浏览器打开就能用，功能完全一样，不需要任何审核。
